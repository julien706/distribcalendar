je souhaite une application web pour mobile qui permet de géré et suivre la distribution des calendrier. 1er étaple, ajout des rue avec les numéros (paire/impaire) 2eme partie validé le passage(fait, a repasser 1er fois, a repasser 1er fois , refus , hinabité.) avec des observation au besoin. 3eme re passer avec validation. je veux que les adresses ajouter se position sur une carte avec leur statut.
